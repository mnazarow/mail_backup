# 4. Конфигурация

## Файл конфигурации

Основные параметры хранятся в `config.yaml`. Путь ищется по порядку:
1. аргумент `--config`;
2. переменная окружения `MAILARCHIVER_CONFIG`;
3. `/etc/mailarchiver/config.yaml`;
4. `<проект>/config/config.yaml`.

Пример со всеми параметрами и комментариями — `config/config.example.yaml`. Все параметры имеют
разумные значения по умолчанию: меняйте только нужное.

Большинство параметров можно менять «на лету» в веб-интерфейсе (раздел «Настройки») — они
сохраняются в БД и переопределяют значения из файла. Полное описание каждого параметра — в
[05-parameters-reference.md](05-parameters-reference.md) и во всплывающих подсказках интерфейса.

Проверить корректность конфигурации:
```bash
mailarchiver -c /etc/mailarchiver/config.yaml check-config
```

## Подключение почтового ящика

В интерфейсе: **Почтовые ящики → Добавить ящик**. Поля:

- **Название** — любое понятное имя.
- **IMAP-сервер** и **Порт** — см. таблицу провайдеров ниже.
- **Шифрование** — SSL/TLS (порт 993, обычный выбор) или STARTTLS (порт 143).
- **Логин** и **Пароль** — обычно нужен «пароль приложения» (см. ниже).
- **Способ входа** — «Пароль» или «OAuth2».

Кнопка **«Проверить подключение»** войдёт в ящик и покажет список папок.

### Настройки популярных провайдеров

| Провайдер | IMAP-сервер | Порт/шифрование | Примечание |
|-----------|-------------|-----------------|-----------|
| Яндекс.Почта | `imap.yandex.ru` | 993 / SSL | Включить IMAP; пароль приложения |
| Mail.ru | `imap.mail.ru` | 993 / SSL | Пароль для внешних приложений |
| Gmail | `imap.gmail.com` | 993 / SSL | OAuth2 или пароль приложения (с 2FA) |
| Microsoft 365 | `outlook.office365.com` | 993 / SSL | Обычно только OAuth2 |
| Свой сервер | адрес сервера | 993 / SSL или 143 / STARTTLS | — |

### Пароли приложений

Яндекс, Mail.ru, Gmail и другие часто не принимают обычный пароль для сторонних программ. Нужно:
1. включить доступ по IMAP в настройках почты;
2. создать отдельный «пароль приложения» и указать его в MailArchiver.

## OAuth2 (Gmail, Microsoft 365)

Если провайдер отключил вход по паролю, выберите способ входа **OAuth2** и заполните:
- **Client ID** и **Client Secret** — из консоли разработчика Google/Microsoft (создайте OAuth-приложение с доступом к почте/IMAP);
- **Refresh Token** — долгоживущий токен, полученный при первичной авторизации приложения;
- **Token URL**:
  - Google: `https://oauth2.googleapis.com/token`
  - Microsoft: `https://login.microsoftonline.com/common/oauth2/v2.0/token`

MailArchiver сам обменивает refresh-токен на access-токен и входит по механизму XOAUTH2. Токены
хранятся в БД в зашифрованном виде.

## Внутренние серверы с самоподписанным сертификатом

Если ваш IMAP-сервер использует самоподписанный сертификат, отключите в настройках
«Проверять TLS-сертификат IMAP» (`security.imap_ssl_verify`). Учтите: это снижает защиту от подмены,
используйте только в доверенной сети.
