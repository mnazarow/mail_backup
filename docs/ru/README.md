# Документация MailArchiver

> 📖 **Самый удобный способ читать документацию** — открыть её из веб-интерфейса
> (кнопка «Документация» вверху справа) или по адресу `http://АДРЕС_ИНТЕРФЕЙСА/static/docs/index.html`
