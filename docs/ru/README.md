# Документация MailArchiver

> 📖 **Самый удобный способ читать документацию** — раздел «📖 Документация» в меню веб-интерфейса
> (оглавление и поиск по тексту; кнопка «📖 Справка» вверху справа открывает главу о разделе, в котором
> вы находитесь) или отдельная страница `http://АДРЕС_ИНТЕРФЕЙСА/static/docs/index.html`
