# 11. Устранение неполадок

## Диагностика

- Логи службы: `journalctl -u mailarchiver -n 100 --no-pager` (или раздел «Логи» в интерфейсе).
- Проверка конфигурации: `mailarchiver -c /etc/mailarchiver/config.yaml check-config`.
- Для подробностей временно поднимите уровень логирования до `DEBUG` (Настройки → Логирование).

## Частые проблемы

| Симптом | Причина и решение |
|---------|-------------------|
| «Аутентификация IMAP не удалась» | Неверный логин/пароль, либо нужен «пароль приложения»/OAuth2. Включите IMAP в настройках почты, создайте пароль приложения. |
| «Ошибка TLS/SSL» | Неверный порт/режим шифрования. SSL — порт 993, STARTTLS — порт 143. Для самоподписанного сертификата отключите проверку сертификата. |
| «Превышено время ожидания» | Медленная сеть/сервер. Увеличьте `backup.socket_timeout_s` и `backup.connect_timeout_s`. |
| «Не удалось соединиться с IMAP-сервером» | Проверьте адрес хоста, порт, доступность сервера и файрвол. |
| Бэкап идёт слишком медленно | Увеличьте `backup.fetch_batch_size`; проверьте лимиты почтового сервера. |
| Экспорт `.pst` не открывается в Outlook | Встроенный движок экспериментальный. Используйте Aspose (с лицензией) или экспорт EML/MBOX. |
| Импорт `.pst` не работает | Не установлен `readpst`. Debian/Ubuntu: `sudo apt install pst-utils`; RHEL: `sudo dnf install libpst`. |
| Служба не запускается | Смотрите `journalctl -u mailarchiver -n 50`. Частые причины: занят порт, ошибка в `config.yaml`, нет прав на каталог данных. |
| «Недостаточно места на диске» | Включите ретеншн (`retention.keep_days`) или сжатие писем (`storage.compress`), либо расширьте диск. |
| Не открывается веб-интерфейс снаружи | По умолчанию слушает `127.0.0.1`. Настройте reverse proxy с HTTPS или используйте SSH-туннель. |
| Не приходят уведомления | Проверьте параметры SMTP (хост, порт, шифрование, логин/пароль) и что включено «Уведомлять об ошибках». |
| WebSocket не обновляет дашборд (за прокси) | В reverse proxy пробросьте заголовки `Upgrade`/`Connection` (см. пример nginx в полной документации). |

## Забыт пароль администратора

```bash
sudo -u mailarchiver /opt/mailarchiver/venv/bin/mailarchiver \
  -c /etc/mailarchiver/config.yaml reset-password -u admin
```

## Проверка целостности локальной копии

В интерфейсе: меню ящика (⋯) → «Проверить целостность копии». Задание сверит файлы на диске с
индексом БД и сообщит об отсутствующих или повреждённых письмах.

## Рассинхронизация индекса и файлов

Если файлы копий были удалены/перемещены вручную, запустите проверку целостности, а затем повторный
бэкап — недостающие письма будут докачаны заново.
