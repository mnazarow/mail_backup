# 1. Введение

**MailArchiver** — сервис для Linux, который по расписанию делает локальные резервные копии
почтовых ящиков по протоколу IMAP, позволяет выгрузить эти копии в файл `.pst` для Microsoft
Outlook и восстановить письма обратно на IMAP-сервер. Управление — через веб-интерфейс на русском
языке с подсказкой к каждому параметру.

## Для кого

- Администраторам, которым нужен надёжный архив корпоративной почты.
- Пользователям, которые хотят иметь офлайн-копию своих писем и открывать её в Outlook.
- Всем, кому важно уметь **восстановить** письма, если они пропали на сервере.

Документация написана так, чтобы с сервисом справился даже не специалист.

## Что делает программа простыми словами

Она регулярно «скачивает» все письма из ваших ящиков и хранит их копию на вашем сервере
(по одному файлу `.eml` на письмо — это надёжно и совместимо со многими программами). Из этой
копии в любой момент можно получить файл `.pst` для Outlook или «залить» письма обратно на почтовый
сервер.

## Ключевые возможности

- **Инкрементальный бэкап по IMAP** — докачиваются только новые письма; сохраняются папки и флаги.
  Переезд почты на другой сервер не удваивает архив (письма узнаются по Message-ID, размеру и дате), а
  письма старше срока хранения ящика не скачиваются вовсе.
- **Экспорт в `.pst`** с вложениями — встроенным движком без внешних программ (Unicode, Outlook
  2003+) или через Aspose (в том числе ANSI для Outlook 97–2002), а также в EML и MBOX.
- **Восстановление** из копии обратно на любой IMAP-сервер.
- **Импорт из `.pst` и `.ost`** без внешних программ: письма из файла Outlook любой версии — на
  почтовый сервер или сразу в локальную копию ящика, с папками, вложениями, флагами и датами
  получения. Файл загружается через интерфейс (до 2 ГБ) или берётся прямо с сервера — тогда его
  размер не ограничен.
- **Расписание** автоматического копирования (cron/интервалы) и **копирование всех ящиков по
  очереди** — одно задание в заданное время копирует ящики строго по одному, начиная с давно не
  копировавшихся, с паузой между ящиками и остановкой к началу рабочего дня.
- **Групповые действия**: одно действие сразу для сотен ящиков (копирование, копия «с нуля»,
  включение, срок хранения, удержание, расписания, сервер и способ входа, папки, выгрузка,
  восстановление, проверка папок на сервере, переиндексация поиска, удаление) — с проверкой по
  каждому ящику до запуска и историей операций; добавление ящиков списком и список ящиков в Excel.
- **Прежние копии после «с нуля»** сами сравниваются с новыми: письма, которых в новой копии нет,
  можно вернуть в архив, а прежнюю копию — удалить без потери писем.
- **Очередь заданий** с приоритетами, лимитом нагрузки и повторами при сбоях.
- **Живая статистика**, мониторинг операций, логи, история, аудит.
- **Контроль ящиков**: проверка паролей всех ящиков одной кнопкой, даты первой и последней копии,
  отборы «с неправильным паролем», «без резервных копий», «копия устарела».
- **Сотрудники**: справочник из кадровой выгрузки (CSV/XLSX/XML, файл или ссылка) с автоматическим
  заведением ящиков.
- **Роль «Оператор»**: сотрудник, который следит за копированием и запускает его, но не читает
  письма, не меняет настроек и ничего не удаляет.
- **Безопасность**: вход по паролю, двухфакторный вход (код из приложения), защита от подбора,
  вход сотрудников в свой архив по паролю ящика, шифрование паролей ящиков и — по желанию — самих
  писем на диске (AES-256-GCM), OAuth2, журнал безопасности с блокировками и событиями.
- **Копия вне сервера**: каждый день — в сетевую папку, на другой сервер по SSH (rsync) или в
  S3-хранилище, вместе со снимками базы; восстановление после потери сервера одной командой.
- **Мониторинг**: метрики для Prometheus и Zabbix, еженедельная сводка на почту.
- **Поиск по письмам** во всех ящиках: по теме, адресам, именам вложений и тексту, с записью
  каждого поиска в аудит.
- **Вход в ящики через администратора почты** — без сбора паролей сотрудников (если почтовый
  сервер это умеет: Dovecot, Cyrus, Zimbra).
- **Сервер Axigen**: сверка учётных записей сервера с архивом (кто не копируется, кого удалили, у кого
  закрыт вход или полный ящик), копирование и восстановление ящиков через FTP Backup без паролей
  сотрудников, изменения на сервере по кнопке с проверкой (закрыть вход, сменить пароль, удалить с
  сервера письма, которые уже в архиве, создать или удалить учётную запись), слежение за очередью,
  лицензией и квотами, консоль только для чтения и журнал всех команд.
- **Ящики на сервере**: групповые действия с самим почтовым сервером — у учётных записей Axigen
  (вход и пароли с файлом для раздачи, службы, квоты, псевдонимы по шаблону, ФИО и отдел из
  «Сотрудников», создание учётных записей списком) и у ящиков любого сервера по IMAP (перенос старых
  писем, папки, отметки, проверка входа, отчёт о месте); очистка корзины, спама, старых писем и папок —
  только если всё удаляемое уже в архиве.
- **Уволенные сотрудники**: последняя копия, выключение копирования, удержание архива на годы.
- **Установка и обновление скриптами**: проверка перед обновлением без остановки службы
  (`update.sh --check`), откат при неудаче с показом причины, установка на сервер без интернета из
  автономного архива.
- **Отчёт «Одинаковые вложения»**: сколько места сэкономило бы хранение одной копии рассылок и
  логотипов.

## Важное про экспорт в `.pst`

`.pst` — закрытый формат Microsoft, его спецификация опубликована как [MS-PST]. В MailArchiver три
пути:

1. **Встроенный (native)** — собственный генератор `.pst` без внешних программ и лицензий. Пишет
   формат **Unicode** (Outlook 2003 и новее): папки ящика, письма с отправителем, получателями
   («Кому», «Копия», «Скрытая»), датами и флагами, текстом и HTML-версией, **со всеми вложениями**
   (картинки из текста письма остаются на своих местах, пересланные письма прикладываются файлами
   `.eml`). `INBOX` становится «Входящими», корзина — «Удалёнными». Большой ящик делится на файлы
   до 1,9 ГБ. Файл проверяется независимыми читателями `.pst` (libpff, `readpst`); перед массовой
   выгрузкой откройте пробный файл в своей версии Outlook.
2. **Aspose** — `.pst` через коммерческую библиотеку Aspose.Email (нужна лицензия); умеет и старый
   формат ANSI для Outlook 97–2002.
3. **EML / MBOX** — всегда доступны, без потерь; Outlook импортирует их (перетаскиванием или через
   конвертеры).

Подробнее — в разделе «Экспорт в PST» полной документации (`/static/docs/index.html`).
