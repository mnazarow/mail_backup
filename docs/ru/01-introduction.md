# 1. Введение

**MailArchiver** — сервис для Linux, который по расписанию делает локальные резервные копии
почтовых ящиков по протоколу IMAP, позволяет выгрузить эти копии в файл `.pst` для Microsoft
Outlook и восстановить письма обратно на IMAP-сервер. Управление — через веб-интерфейс на русском
языке с подсказкой к каждому параметру.

## Для кого

- Администраторам, которым нужен надёжный архив корпоративной почты.
- Пользователям, которые хотят иметь офлайн-копию своих писем и открывать её в Outlook.
- Всем, кому важно уметь **восстановить** письма, если они пропали на сервере.

Документация написана так, чтобы с сервисом справился даже не специалист.

## Что делает программа простыми словами

Она регулярно «скачивает» все письма из ваших ящиков и хранит их копию на вашем сервере
(по одному файлу `.eml` на письмо — это надёжно и совместимо со многими программами). Из этой
копии в любой момент можно получить файл `.pst` для Outlook или «залить» письма обратно на почтовый
сервер.

## Ключевые возможности

- **Инкрементальный бэкап по IMAP** — докачиваются только новые письма; сохраняются папки и флаги.
- **Экспорт в `.pst`** для всех версий Outlook (ANSI для 97–2002, Unicode для 2003+), а также в EML и MBOX.
- **Восстановление** из копии обратно на любой IMAP-сервер.
- **Импорт из `.pst`** на IMAP-сервер.
- **Расписание** автоматического копирования (cron/интервалы).
- **Очередь заданий** с приоритетами, лимитом нагрузки и повторами при сбоях.
- **Живая статистика**, мониторинг операций, логи, история, аудит.
- **Безопасность**: вход по паролю, шифрование паролей ящиков, защита от подбора, OAuth2.

## Важное про экспорт в `.pst`

`.pst` — закрытый формат Microsoft. На Linux **надёжно** создавать корректный `.pst` умеет по сути
только коммерческая библиотека **Aspose.Email**; полностью бесплатных генераторов `.pst` под Linux
нет (open-source умеет только читать `.pst`). Поэтому в MailArchiver три пути:

1. **Aspose** — надёжный `.pst` (нужна лицензия для промышленного использования).
2. **Встроенный (native)** — бесплатный **экспериментальный** генератор `.pst` без зависимостей
   (проверяется на чтение утилитой `readpst`; всё равно рекомендуется проверить в своём Outlook).
3. **EML / MBOX** — всегда доступны, без потерь; Outlook импортирует их (перетаскиванием или через
   конвертеры).

Подробнее — в разделе «Экспорт в PST» полной документации (`/static/docs/index.html`).
